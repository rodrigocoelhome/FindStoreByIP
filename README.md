# FindStoreByIP
FindStoreByIP is a Python script that identifies information from IP addresses. It uses the ping -a command to resolve machine names and extract information from the ping response.

O FindStoreByIP é um script Python que identifica informações a partir de endereços IPs. Ele utiliza o comando ping -a para resolver os nomes das máquinas e extrair a informação do retorno do ping.
